# Java OOP Lab Assignments

Complete Java solutions for Assignments 1–7, organized by assignment. Each program is an independent source file.

## Compile and run

Example: javac Assignment-1/EvenOddZero.java, then run with java -cp Assignment-1 EvenOddZero. A JDK must be installed.

## Contents
- Assignment 1: Conditions and data types
- Assignment 2: Mathematical programs and loops
- Assignment 3: Classes and constructors
- Assignment 4: Arrays and matrices
- Assignment 5: String handling
- Assignment 6: Inheritance and method overriding
- Assignment 7: Searching and sorting

Array positions are 1-based. Java substring indices are 0-based with an exclusive end index. Binary search sorts the array before searching.
