## Compile and run

Install a Java Development Kit (JDK), open a terminal in the repository root, and compile a source file. For example:

```bash
javac Assignment-1/EvenOddZero.java
java -cp Assignment-1 EvenOddZero
```

Repeat with the required path and public class name for another program. Each program is intended to run independently.

## Notes

- Positions in the array menu are **1-based**.
- Java substring indices are **0-based**, and the ending index is exclusive.
- The binary-search program sorts the entered array before searching, so its reported position refers to the sorted array.
- This README update is on the `docs/readme-assignment-links` branch. Merge it into `main` when you are satisfied with the changes.
